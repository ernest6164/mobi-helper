## 3. 개별 캐릭터 상세 정보 (`(서버명)_(캐릭터명).md`)

```markdown
## 기타 상태
* **인벤토리 무게**: 1641.1486 / 2090.0
* **현재 체력**: 93092 / 93092

* **던컨_아미나_inventory.csv**: 2026-10-04 22:31

* **던컨_bank_all.csv**: 2026-10-04 22:31

```

## 4. 인벤토리 및 보관함 재고 CSV (`*.csv`)

인벤토리, 개인 금고, 서버 공용 금고의 아이템 목록을 관리하는 테이블 데이터입니다.

* **인벤토리**: `(서버명)_(캐릭터명)_inventory.csv`
* **개인 보관함**: `(서버명)_(캐릭터명)_bank.csv`
* **공용 보관함**: `(서버명)_bank_all.csv`

```csv
Location,DisplayName,Category,CategoryDisplayName,Count,IsLocked
inventory,정령의 날개,Currency,재화,53357,False
inventory,룬의 파편,Ingredient,재료,3733,False
inventory,연금술 부스러기,Ingredient,재료,44658,False
inventory,얼음,Ingredient,재료,22,False
inventory,황금 양털,Ingredient,재료,1,True
```

## 5. 퀘스트 및 일일/주간 미션 (`(서버명)_(캐릭터명)_quest.md`)

해당 캐릭터의 진행 중인 퀘스트 목록 및 일일/주간 미션 수행 상황을 기록하는 문서입니다.

```markdown
# 퀘스트 및 미션 진행 상황: 아미나

* **서버**: 던컨
* **최종 갱신 일시**: 2026-10-04 22:33

## 1. 퀘스트 진행 내역

| 구분 | 퀘스트명 | 세부 목표 | 진행 상태 | 완료 여부 |
| :--- | :--- | :--- | :--- | :---: |
| 메인 | [주간 목표] 모험가 길드의 정기 의뢰 (5) | 심층 던전 클리어 2/3 | 2/3 | 진행 중 |
| 메인 | [주간 목표] 모험가 길드의 정기 의뢰 (5) | 던전 클리어 5/5 | 5/5 | ✅ 완료 |
| 메인 | [주간 목표] 모험가 길드의 정기 의뢰 (5) | 사냥터 클리어 5/5 | 5/5 | ✅ 완료 |
| 메인 | 모험가 길드의 고난도 심층 공략 | 심층 던전 (매우 어려움) 클리어 | 0/1 | 진행 중 |
| 사이드 | 법황청의 특별 의뢰 | 심층 던전 클리어 | 0/1 | 진행 중 |

## 2. 일일 미션 수행 내역

| 미션명 | 내용 | 진행도 | 완료 여부 | 보상 수령 |

| 에린에 돌아왔습니다 | 접속하기 | 1/1 | ✅ 완료 | 수령 완료 |
| 오늘도 던전 한 바퀴 | 던전 3회 토벌 | 3/3 | ✅ 완료 | 수령 완료 |
```

## 8. 사용자 정의 특수 규칙 (`workflows_custom.md`)

스킬을 사용하는 개개인이 필요한 규칙을 추가하여 시스템의 기본 동작을 무시하거나 변경해 최우선으로 적용하도록 규정하는 문서입니다.

```markdown
# 사용자 정의 특수 규칙 (Custom Rules)

본 문서에 정의된 특수 규칙은 스킬의 기존 기본 동작보다 최우선으로 적용되며, 기존 워크플로우를 무시하거나 변경하여 동작합니다.

## 특수 규칙 목록
* 재료 채집 전, "(특정 재료) (특정 갯수) 개를 채집합니다." 를 채팅으로 입력한다.
```
