# 데이터 관리 원칙 및 명명 규칙 (Data Management)

* **갱신 일시**: 2026년 10월 5일

본 문서는 마비노기 모바일 헬퍼 시스템에서 생성 및 관리하는 데이터의 동기화 원칙, 문서 구조, 명명 규칙을 정의합니다.

---

## 1. 캐릭터 정보 수집 및 정합성 관리

* **캐릭터 정보 수집 방식**:
  * 한 계정 내에는 서버당 최대 6개(`MAX_CHARACTERS_PER_SERVER`)의 캐릭터가 존재할 수 있습니다.
  * AI 커넥터 특성상 한 번에 접속 중인 하나의 캐릭터 정보만 조회 가능하므로, 사용자에게 각 캐릭터별 접속을 유도하여 개별적으로 정보를 수집합니다.
  * **(중요)** 커넥터 API에서 캐릭터 이름(닉네임)을 반환하지 않으므로, 정보 수집 시 항상 **사용자에게 현재 접속 중인 캐릭터명이 무엇인지 확인 요청**해야 합니다.
* **계정 캐릭터 정합성 관리**:
  * 서버 및 계정 내 실제 보유 중인 캐릭터 수를 별도로 파악하여 관리합니다.
  * 수집된 캐릭터 문서 수와 실제 캐릭터 수가 다를 경우, 사용자에게 나머지 캐릭터로의 접속 및 정보 갱신을 요청/권장합니다.
* **최종 갱신 일시 표기**:
  * 데이터 정합성을 확인하기 위해 각 캐릭터 데이터마다 **최종 갱신 일시**를 명시합니다.
  * 재고 정보의 경우, CSV 파일 내부 대신 `(서버명)_(캐릭터명).md` 문서 내에 각 CSV 파일별 최종 업데이트 일시를 기록하여 관리합니다.
* **상태 유지 원칙**:
  * 변경 이력(diff)은 별도로 관리하지 않으며, 문서는 항상 **최신 상태로 덮어쓰기**합니다.

---

## 2. 데이터 시트 구조 및 우선순위

* **사용자 정의 특수 규칙 (`workflows_custom.md`)**:
  * 스킬을 사용하는 사용자가 개별적으로 정의한 특수 동작 규칙입니다.
  * `data/` 폴더 내에 `workflows_custom.md`가 존재할 경우, 스킬의 기존 기본 동작이나 워크플로우를 무시하거나 변경하여 **해당 규칙을 최우선으로 적용**합니다.
* **개별 캐릭터 시트 (`(서버명)_(캐릭터명).md`)**: 각 캐릭터의 상세 스탯, 점수, 상태를 하나의 시트로 분리하여 유지합니다.
* **통합 요약 시트 (`characters.md`)**: 계정 내 모든 캐릭터들의 핵심 정보(직업, 전투력, 생활력, 갱신일)를 한눈에 볼 수 있는 요약 시트입니다.
* **재고 목표치 관리 (`target.md`)**: 관리 대상 아이템의 목표치를 마크다운 테이블로 관리합니다.
  * **우선순위 (`TARGET_PRIORITY_RULE`)**: 목록에서 **아래쪽에 위치한 항목일수록 높은 우선순위**를 가집니다. 채집 시 아래쪽 항목부터 우선적으로 진행합니다.
* **레시피 관리 (`recipes.csv`)**: 가공/제작 레시피 정보를 수집하여 데이터베이스 형태로 관리합니다.
* **동작 및 판단 우선순위**:
  1. **사용자 정의 특수 규칙 (`data/workflows_custom.md`)** (존재 시 최우선 적용)
  2. **API 응답**
  3. **유저의 명령**
  4. **로컬 프로젝트 내 저장된 내용 및 기본 스킬 동작**

## 3. 파일 명명 규칙 (Naming Convention)

모든 데이터 문서는 `data/` 디렉토리 하위에 위치합니다.

| 파일명 | 설명 | 포맷 |
| :--- | :--- | :---: |
| `workflows_custom.md` | 사용자가 개별 정의한 특수 규칙 문서 (존재 시 기본 동작보다 최우선 적용) | Markdown |
| `characters.md` | 계정 내 모든 캐릭터의 요약 정보 시트 | Markdown |
| `(서버명)_(캐릭터명).md` | 개별 캐릭터 상세 정보 및 연관 데이터 갱신 일시 | Markdown |
| `(서버명)_(캐릭터명)_inventory.csv` | 해당 캐릭터의 인벤토리 아이템 목록 | CSV |
| `(서버명)_(캐릭터명)_bank.csv` | 해당 캐릭터 전용 개인 보관함(금고) 아이템 목록 | CSV |
| `(서버명)_bank_all.csv` | 계정 내 동일 서버 캐릭터들이 공유하는 공용 보관함 아이템 목록 | CSV |
| `(서버명)_(캐릭터명)_quest.md` | 해당 캐릭터의 퀘스트 및 일일/주간 미션 진행 상태 | Markdown |
| `target.md` | 채집 아이템별 재고 목표치 설정 문서 | Markdown |
| `recipes.csv` | 수집된 가공/제작 레시피 정보 데이터베이스 | CSV |
| `path.txt` | `MabinogiMobile_CLI.exe` 도구의 로컬 절대 경로 | Text |
