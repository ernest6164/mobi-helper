# 부록 및 환경 설정 가이드 (Appendix)

* **갱신 일시**: 2026년 10월 5일

본 문서는 특정 환경(Windows, IDE, Git 등) 또는 특정 AI 에이전트 플랫폼(Antigravity 등)에 의존적인 부가 기능, 환경 설정 가이드 및 활용 팁을 다룹니다.

---

## 1. 특정 AI 에이전트 플랫폼(Antigravity) 연동 가이드

본 프로젝트는 특정 AI에 종속되지 않으나, **Antigravity** 환경에서 스킬로 활용할 경우 다음과 같이 로컬에 배치하여 전역 또는 프로젝트 스킬로 로드할 수 있습니다.

* **글로벌 스킬 등록**:
  * 에이전트 플랫폼의 글로벌 스킬 디렉토리에 본 저장소를 배치해 두면 에이전트가 실행되는 모든 워크스페이스에서 `SKILL.md`를 자동으로 탐색하여 인식합니다.
* **프로젝트 서브모듈 등록**:
  * 특정 프로젝트의 스킬 디렉토리 하위에 서브모듈 또는 디렉토리 형태로 추가하여 팀원과 공유할 수 있습니다.

---

## 2. CSV 문서 열람 및 관리

본 시스템에서 생성된 재고 관리 등의 `.csv` 데이터 파일은 아래와 같은 방법으로 쉽게 열람하고 관리할 수 있습니다.

* **스프레드시트 프로그램 활용**: Microsoft Excel, Google Sheets 등 범용 스프레드시트 도구에서 파일을 열어 표 형태로 편리하게 확인 및 편집할 수 있습니다.
* **코드 에디터 확장 도구**: VS Code 등의 에디터 환경에서는 Rainbow CSV, Edit csv 등의 확장 플러그인을 활용하여 에디터 내부에서 바로 표 형태로 정렬하여 조회할 수 있습니다.

---

## 3. 토큰 비용 절감을 위한 로컬 스크립트 및 venv 가상환경 활용

AI 에이전트를 통해 텍스트나 데이터를 대량으로 직접 파싱하면 컨텍스트 토큰 소모량이 커질 수 있습니다.

* **로컬 처리 권장**: 대량의 데이터 가공이나 반복적인 파싱 작업은 로컬 Python 스크립트 등을 작성하여 `scratch/` 디렉토리에서 실행 및 처리한 뒤, 최종 결과물만을 문서로 동기화하는 방식을 권장합니다.
* **Python venv 가상환경 필수 사용**:
  * 로컬 Python 스크립트 실행 시 오염 방지 및 일관된 환경을 위해 반드시 프로젝트 내 **`venv` 가상환경(`python.exe`)**을 통해 실행합니다.
  * 구체적인 인터프리터 경로 및 실행 방식은 `scratch/know-how.md`를 참조합니다.

---

## 4. 에이전트 자율 모드(Auto Mode) 활용

AI 에이전트 도구가 제공하는 자율 실행 모드나 연속 작업 기능을 활용하면 자동화 효율을 높일 수 있습니다.

* **작업 연속성 확보**: 파일 생성, 데이터 갱신, CLI 도구 연동 등 여러 단계로 구성된 복합 작업을 수행할 때 자율 실행 모드를 활성화하면, 중간 대기 없이 목표가 완료될 때까지 작업을 원활하게 진행할 수 있습니다.

---

## 5. 버전 관리 도구(Git) 환경 구성

프로젝트 내 문서와 운영 데이터(스킬 설정, 템플릿, 규칙 등)를 백업하고 안전하게 버전을 관리하기 위해 Git 환경을 구성할 수 있습니다.

* **설치 및 환경 변수**: Windows 환경에 적합한 패키지 관리자나 공식 설치 프로그램을 통해 Git을 설치하고, 터미널 환경에서 도구 명령어가 정상 인식될 수 있도록 PATH 환경 변수 설정을 확인합니다.
* **로컬 절대 경로 실행**: PATH에 등록되어 있지 않은 경우, `scratch/know-how.md`에 기재된 로컬 Git 절대 경로를 호출하여 사용합니다.

---

## 6. 원격 저장소(GitHub 등) 연동 및 동기화

로컬에서 관리 중인 프로젝트 설정과 문서들을 원격 저장소에 백업하여 동기화할 수 있습니다.

* **원격 저장소 연결**: GitHub 등 원격 호스팅 서비스에서 생성한 저장소 주소를 로컬 프로젝트에 연결하고 브랜치를 설정합니다.
* **인증 및 동기화**: 브라우저 기반 인증(Git Credential Manager) 또는 개인 액세스 토큰(PAT)을 활용하여 인증을 완료한 후 변경 사항을 원격 저장소에 안전하게 업로드 및 동기화합니다.

---

## 7. 명령어 실행 권한 및 보안 관리

AI 어시스턴트가 CLI 도구 호출이나 스크립트 실행 등을 진행할 때, 개발 환경 및 도구 설정에 따라 매번 사용자의 수동 승인을 요구하거나 차단될 수 있습니다.

* **원활한 자동화 환경 구성**: 반복적인 명령어 실행 시 매번 발생하는 대기 시간을 줄이고 자동화 흐름을 원활히 유지하려면, 사용 중인 IDE나 AI 에이전트 환경의 보안/권한 설정을 확인하여 신뢰할 수 있는 도구 및 스크립트의 실행 권한을 사전에 적절히 부여하는 것을 권장합니다.
* **보안 유의**: 실행 권한을 포괄적으로 허용할 경우 시스템 보안에 유의해야 하므로, 현재 프로젝트와 관련된 검증된 도구에 한해 안전하게 관리하는 것이 좋습니다.

---

## 8. 시스템 종속 환경 노하우 문서 (`scratch/know-how.md`)

* 특정 로컬 머신에 종속적인 도구 경로(Git 절대 경로, Python venv 경로 등), 실행 노하우, 문제 해결 팁 등은 공용 저장소 문서에 하드코딩하지 않고 로컬의 `scratch/know-how.md`에 기록하여 관리하고 참조합니다.
