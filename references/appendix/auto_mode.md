# 에이전트 자율 모드(Auto Mode) 활용 가이드

* **갱신 일시**: 2026년 10월 5일

AI 에이전트 도구가 제공하는 자율 실행 모드나 연속 작업 기능을 활용하면 자동화 효율을 극대화할 수 있습니다.

---

## 1. 작업 연속성 확보
* 파일 생성, 데이터 갱신, CLI 도구 연동 등 여러 단계로 구성된 복합 작업을 수행할 때 자율 실행 모드를 활성화하면, 중간 대기 없이 목표가 완료될 때까지 작업을 원활하게 진행할 수 있습니다.
* 작업 중간에 발생하는 가벼운 예외 상황(일시적 응답 지연 등)도 에이전트가 자체적으로 재시도하여 작업을 완수합니다.
