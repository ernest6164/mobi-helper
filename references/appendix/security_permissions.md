# 명령어 실행 권한 및 보안 관리 가이드

* **갱신 일시**: 2026년 10월 5일

AI 어시스턴트가 CLI 도구 호출이나 스크립트 실행 등을 진행할 때, 개발 환경 및 도구 설정에 따라 매번 사용자의 수동 승인을 요구하거나 차단될 수 있습니다.

---

## 1. 원활한 자동화 환경 구성
* 반복적인 명령어 실행 시 매번 발생하는 대기 시간을 줄이고 자동화 흐름을 원활히 유지하려면, 사용 중인 IDE나 AI 에이전트 환경의 보안/권한 설정을 확인하여 신뢰할 수 있는 도구 및 스크립트의 실행 권한을 사전에 적절히 부여하는 것을 권장합니다.

## 2. 보안 유의사항
* 실행 권한을 포괄적으로 허용할 경우 시스템 보안에 유의해야 하므로, 현재 프로젝트와 관련된 검증된 도구(`MabinogiMobile_CLI.exe`, 프로젝트 내 `scripts/` 등)에 한해 안전하게 관리하는 것이 좋습니다.
