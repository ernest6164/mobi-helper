# 버전 관리 도구(Git) 환경 구성 가이드

* **갱신 일시**: 2026년 10월 5일

프로젝트 내 문서와 운영 데이터(스킬 설정, 템플릿, 규칙 등)를 백업하고 안전하게 버전을 관리하기 위해 Git 환경을 구성할 수 있습니다.

---

## 1. 설치 및 환경 변수 점검
* Windows 환경에 적합한 패키지 관리자(winget, scoop 등)나 공식 설치 프로그램을 통해 Git을 설치합니다.
* 터미널 환경에서 `git` 명령어가 정상적으로 인식될 수 있도록 PATH 환경 변수 설정을 확인합니다.

## 2. 로컬 절대 경로 실행
* PATH에 등록되어 있지 않은 경우, `data/know-how.md` 또는 `data/environments.json`에 기재된 로컬 Git 절대 경로(예: `C:\Program Files\Git\cmd\git.exe`)를 직접 호출하여 사용합니다.
