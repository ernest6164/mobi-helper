# 템플릿: 사용자 정의 특수 규칙 (`workflows_custom.md`)

* **대상 파일**: `data/workflows_custom.md`
* **설명**: 스킬을 사용하는 개개인이 필요한 규칙을 추가하여 API 응답 다음(2순위)으로 시스템의 기본 동작보다 우선 적용하도록 규정하는 문서입니다.

---

```markdown
# 사용자 정의 특수 규칙 (Custom Rules)

본 문서에 정의된 특수 규칙은 API 응답 다음으로 우선 적용(2순위)되며, 스킬의 기존 기본 동작보다 우선하여 기존 워크플로우를 무시하거나 변경하여 동작합니다.

## 특수 규칙 목록
* 재료 채집 전, "(특정 재료) (특정 갯수) 개를 채집합니다." 를 채팅으로 입력한다.
```
