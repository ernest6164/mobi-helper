## 2. 문서 작성 및 관리 원칙

1. **태그 기반 검색 (`#tag`)**:
   * 각 지식 문서 상단에는 반드시 `#` 기호로 시작하는 해시태그를 1개 이상 명시합니다.
2. **출처 및 갱신 주기 관리**:
   * `사용자 직접 작성` 또는 `인터넷 검색 수집`으로 구분하여 명시합니다.
   * `최종 갱신 일시`로부터 1주일(7일) 경과 시 웹 조사를 통해 최신 정보를 갱신합니다.
3. **갱신 여부 (Auto Refresh) 설정**:
   * 기본값은 `yes`이며, 사용자가 `no`로 지정한 문서는 1주일이 경과해도 웹 조사를 생략하고 기존 내용을 유지합니다.
4. **인덱스 동기화**:
   * 새로운 문서가 추가되거나 기존 문서가 수정/삭제될 때 본 `README.md`의 색인 테이블을 항상 최신 상태로 유지합니다.
