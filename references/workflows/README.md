# 마비노기 모바일 헬퍼 표준 작업 흐름 (Workflows)

본 디렉토리는 마비노기 모바일 헬퍼 시스템에서 수행하는 핵심 작업 흐름을 규정합니다.

> [!IMPORTANT]
> **사용자 정의 특수 규칙(`data/workflows_custom.md`) 적용 원칙**:
> `data/workflows_custom.md` 파일이 존재하는 경우, 본 워크플로우에 정의된 기본 동작보다 최우선 적용됩니다.

---

## 세부 워크플로우 색인

| 절 | 작업 흐름명 | 문서 링크 | 핵심 요약 |
| :---: | :--- | :--- | :--- |
| **제1절** | **정보 저장 및 확인** | [`info_sync.md`](./info_sync.md) | 캐릭터 기본 정보, 스탯, 인벤토리/금고 CSV, 퀘스트/미션 저장 및 요약 색인 갱신 |
| **제2절** | **일괄 채집 요청 (재고 보충)** | [`stock_gathering.md`](./stock_gathering.md) | 채집 목표치(`target_gathering.md`) 점검, 타 캐릭터 재고 확인, 부족분 일괄 채집 *(개별 채집 요청 아님)* |
| **제3절** | **일괄 가공 요청 (재고 보충)**<br>*(⚠️ 시험적 기능)* | [`stock_altering.md`](./stock_altering.md) | 가공 목표치 점검, 완료 가공물 일괄 수령 및 빈 슬롯에 부족품 단발성 등록 *(시작 전 정상 동작 불가 가능성 고지 및 승인 필수)* |
| **제4절** | **챗봇 지식 조회 & 채팅 전달** | [`chatbot_chat.md`](./chatbot_chat.md) | 단순 발화/지식 질의 구분, 1주일 갱신 주기 관리, 50자 분할 및 최대 3개 청크 전송 |
| **제5절** | **생활 스킬 집중 육성 (1시간 루프)**<br>*(⚠️ 시험적 기능)* | [`life_skill_leveling.md`](./life_skill_leveling.md) | 사전 질의/대기열 점검 후 채집·최단시간 가공·제작 1시간 순환 수련 *(시작 전 정상 동작 불가 가능성 고지 및 승인 필수)* |
